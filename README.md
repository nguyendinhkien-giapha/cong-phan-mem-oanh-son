# Cổng thông tin phần mềm Oanh Sơn
Upload toàn bộ 6 tệp ở thư mục gốc GitHub Repository. Đảm bảo `index.html`, `style.css`, `apps.js`, `app.js`, `manifest.webmanifest`, `sw.js` cùng cấp.

Mở `apps.js`, điền `appUrl` bằng URL website đã triển khai của từng ứng dụng (GitHub Pages/Netlify), không điền URL repository.

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Cổng chỉ điều hướng, không đồng bộ dữ liệu giữa các phần mềm con.


Cổng hiện có 9 thẻ: 5 phần mềm hiện tại và 4 vị trí dự phòng để bổ sung phần mềm sau này. Khi có phần mềm mới, sửa thẻ dự phòng tương ứng trong `apps.js` và điền `appUrl`.
